maa-cli 日常任务配置手册v0.7.5 · 依据 MAA 集成协议 integration.md + maa-cli 实测

用于把机队账号的「清日常」从 AUTO-MAS 搬到 CLI。日常 = 一条自定义任务链（tasks/*.toml），可自由组合 唤醒→奖励→公招→基建→信用→理智→（肉鸽）。

① 三条路：预定义命令 / 自定义任务 / 日常+肉鸽合链

方式写法适用
预定义命令（单任务）maa startup YoStarJP
maa fight 1-7 -m 1
maa closedown		快速手动单步；不组合
自定义任务链（推荐）tasks/daily_jp.toml + maa run daily_jp完整日常（本文重点）
日常+肉鸽合链日常任务后面接一条 Roguelike（starts_count=99999）机队：每次启动先清日常再连刷肉鸽

# tasks/daily_jp.toml —— 用法: maa run daily_jp -a 127.0.0.1:<口> # 顺序（用户定稿 2026-10-01）：唤醒 → 刷理智 → 公招 → 基建 → 信用 → 奖励 [[tasks]] name = "开始唤醒" type = "StartUp" params = { client_type = "YoStarJP", start_game_enabled = true } [[tasks]] name = "刷理智" type = "Fight" params = { stage = "1-7", medicine = 0, stone = 0 } [[tasks]] name = "公开招募" type = "Recruit" params = { refresh = true, select = [4, 5], confirm = [3, 4], times = 4, skip_robot = true } [[tasks]] name = "基建换班" type = "Infrast" params = { facility = ["Mfg","Trade","Power","Control","Reception","Office","Dorm"], drones = "Money", threshold = 0.3, dorm_trust_enabled = true } [[tasks]] name = "信用购物" type = "Mall" params = { visit_friends = true, shopping = true, buy_first = ["招聘许可"], blacklist = ["加急许可","家具零件"] } [[tasks]] name = "领取奖励" type = "Award" params = { award = true, mail = true }

⑨ 两个独立功能：日常 / 肉鸽（启动前都先关游戏）

日常和肉鸽是两条独立任务文件，分别启动；每次启动前先关游戏（am force-stop），从干净状态拉起，避免残留画面/半途对局导致识别失败。

# 日常（只做日常）: tasks/daily_lX.toml → 唤醒→奖励→公招→基建→信用→刷理智 # 肉鸽（只刷肉鸽）: tasks/rogue_*.toml → 唤醒→肉鸽连刷(99999) # 启动器已封装「先关游戏再发车」： D:\MAA-CLI\rogue_cli_ops.ps1 daily l-1 # 关游戏 → maa run daily_l1 D:\MAA-CLI\rogue_cli_ops.ps1 rogue l-1 # 关游戏 → maa run rogue_sami_l1
  • 日常链尾部就停在「刷理智」，不会再自动接肉鸽。
  • 日常跑完想开刷 → 单独触发一次 rogue <机>（它会先关游戏再拉起）。
  • 一设备一控制者：启动器会自动先停掉该机正在跑的任务。

⑩ 机队落地要点

  • 日服：client_type="YoStarJP"，Fight 的 server="JP"（若开上传）。
  • 一设备一控制者：跑日常前必须停掉该机的肉鸽任务（同设备不能两个 MAA）。
  • 独立状态：每台 MAA_STATE_DIR=state_lX，日志互不串。
  • 跑完不写回：任务文件是只读输入，core 未写字段用默认值；配置不会"污染"。
  • 卡住/报错处理：认不出的界面或任务 Error → 关游戏重开（am force-stop）→ 重跑任务；再不行重启模拟器。
  • 修复命令会认功能：fix <机> 自动修「当前在跑的那个」（日常坏了修日常，肉鸽坏了修肉鸽）；想强制指定就加 daily/rogue：fix2 l-1 daily。
  • 运维命令：rogue_cli_ops.ps1 status（体检）· daily/rogue <机>（启动，自动先关游戏）· fix1/fix2/fix3/fix <机> [daily|rogue]（阶梯修复）。
