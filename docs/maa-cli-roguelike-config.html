maa-cli 肉鸽（Roguelike）配置速查maa-cli v0.7.5 · MaaCore 6.18.0

来源：maa.exe roguelike --help 实测输出（本机 2026-09-30）。唯一必填参数＝主题 THEME，其余全部可省略（走默认值）。

① 主题 THEME（唯一必填）

  • Phantom傀影 · 无难度
  • Mizuki水月 · 骰子
  • Sami萨米 · 密文板/坍缩
  • Sarkaz萨卡兹 · 种子
  • JieGarden界园 · 新
maa.exe roguelike <THEME> [选项…]

② 核心玩法参数

选项可选值默认说明
--mode <MODE> 0 分数 / 1 源石锭 / 4 三层后 / 5 坍缩范式(仅Sami)
（2 已弃用 · 3 未实现）		 0 刷取方式。日常刷肉鸽最常见：0（刷等级）或 1（刷源石锭）。
--squad <SQUAD> 中文分队名 指挥分队 例如"后勤分队"、"突击战术分队"等你自定义分队。
--core-char <CORE> 中文干员名 （不设） 开局核心干员，如"维什戴尔"。设定后序列会优先换到该干员开局。
--roles <ROLES> 中文组合词 先手必胜 开局招募组合，如"取长补短"、"先手必胜"。
--starts-count <N> 数字 ≥1 不设＝永不停 探索次数上限。不填就一直刷到 resource 用尽；1＝只打一局。
--difficulty <D> 数字（难度值） 0 高于主题上限会被封顶。Phantom 无效。2147483647 通常＝MAX。

③ 肉鸽增强 / 限定主题参数

选项主题说明
--start-with-elite-two通用允许开局精二干员。
--only-start-with-elite-two通用只选精二开局（无精二则等待/刷）。
--stop-at-final-boss通用到最终Boss前停止探索（刷积分不碰Boss）。
--refresh-trader-with-diceMizuki 水月用骰子刷新商店，快速过商店回合。
--use-foldartalSami 萨米启用密文板机制（canary 曾遇"密文宣告"卡点，用此开关控制）。
-F / --start-foldartals <LIST>Sami开局携带的密文板列表（期望开局即有的）。
-P / --expected-collapsal-paradigms <LIST>Sami期望的坍缩范式（配合 mode 5）。
--start-with-seedSarkaz 萨卡兹种子开局（仅 mode 1 有效）。

④ 投资（Investment）参数

选项说明
--disable-investment关闭投资（遇到投资不存钱）。挂机刷分常用，防止分被花掉。
--investment-with-more-score开启后投资模式下也尽量拿分数（默认会跳过一些费时动作）。
--investments-count <N>投资次数达到 N 次后停止探索。
--no-stop-when-investment-full投资满后不停止（默认满了会停）。

⑤ 支援干员

选项说明
--use-support使用好友支援干员。
--use-nonfriend-support使用非好友的公开支援干员。

⑥ 连接 / 设备参数

选项说明
-a / --addr <ADDR> 设备 adb 序列号，如本机 127.0.0.1:16384（默认 emulator-5554）。
也可在 profiles/default.toml 的 [connection] address 里配。
-p / --profile <PROFILE> profile 文件名（$MAA_CONFIG_DIR/profiles/<name>.toml）。默认 default.toml，不存在则回退 asst.toml。
--user-resource额外加载配置目录下自定义资源（覆盖同名官方资源）。

⑦ 运行控制

选项说明
--dry-run只解析配置、不连游戏。发车前自检用。
--batch批处理模式，跳过交互式输入提示，用默认值。
--no-summary结束时显示摘要（默认开）。
--no-auto-reconnect断线不自动重连。
-v / -q日志详细 / 安静（可重复叠加）。
--log-file[=PATH]写日志到文件（不写则 stderr）；默认路径 $(maa dir log)/…。

⑧ 参考命令示例

# 本机 #0（日服，水月主题）只打 1 局，默认分队： maa.exe roguelike Mizuki --mode 0 --starts-count 1 --difficulty 2147483647 -a 127.0.0.1:16384 # 挂机刷等级（开始后不停），用指挥分队+精二支持： maa.exe roguelike Sami --mode 0 --core-char 维什戴尔 --use-support -a 127.0.0.1:16384 # 自检不连游戏： maa.exe roguelike Sarkaz --dry-run -p default
  • 更完整的自定义（如多任务链、每日任务）可写在 config/tasks/<name>.toml，用 maa run <name> 执行。
  • 设备/客户端（日服 YoStarJP）等全局设置放在 profiles/default.toml。
