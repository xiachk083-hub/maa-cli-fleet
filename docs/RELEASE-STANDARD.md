# 上线标准（Release Standard）

> 2026-10-01 立 · 缘起：本日三次现场事故（静默加载失败 / 21 个孤儿模拟器打满内存 / running 残留漏跑日常），
> 以及"Go runner 未做 canary 直接全量 49 台"——都是**因为没定义上线门槛**。
> 本文是硬门槛：**过不了就不算上线**。

---

## 1. 分级（按真实影响面，不按代码量）

| 级 | 范围 | 准入门槛 |
|---|---|---|
| **L0 实验** | 本地 / 假账号 / dry-run | 无（随便炸），但产物不得指向真账号 |
| **L1 Canary** | **1 台真账号** | 全链路真跑一次 + **看真结算**（任务链 Completed） |
| **L2 小批** | **3~5 台**，覆盖不同类型（≥2 个服务器、≥1 个带剿灭、≥1 个不带） | 连续 **3 次**成功；无副作用（不重花信用、不重刷剿灭、不误动别号） |
| **L3 全量** | 全部账号 | L2 通过 + **回滚演练**（能退回上一版并恢复原状）+ 首日窗口观察 |

**硬规则**：跨级不许跳；**L3 之前不许开调度器常驻**（手工逐台或 `-once` 填槽）。

## 2. G 清单（每一级都要全过，任何一条不过 = 不上）

| # | 条款 | 怎么验 | 本次反例 |
|---|---|---|---|
| **G1 可停** | 有优雅停止（stop 信号 → 在场任务收尾/停机）；**禁止强杀作为常规手段** | 发 stop，看模拟器是否全停、`running` 是否清空 | 我两次 `Stop-Process` → 孤儿 |
| **G2 可看** | 日志**落盘**（不是 stderr）；状态有可查询的接口/文件 | 断开控制台后日志仍在；`-status` 能看到队列 | 日志写 stderr，常驻进程无控制台 → 全丢 |
| **G3 自愈** | 崩溃/被杀后的残留**自动回收**：`running` 任务、孤儿模拟器、临时文件 | 手杀进程 → 重启 → 看是否自动回收 | running 残留永不回收；孤儿模拟器打满内存 |
| **G4 有界** | 并发上限、重试上限、**资源清扫**（内存/模拟器数） | 压一遍看资源曲线；故意留孤儿看是否被扫 | 21 个模拟器 / 内存 0.7G |
| **G5 禁静默** | 任何加载/解析/连接失败**必须大声报错并停**，不许"0 条也行" | 塞一个坏配置文件看是否报错退出 | 配置被转义咬坏 → 0 账号 → 静默继续 |
| **G6 幂等** | 重复执行不叠加副作用；**"今天已做/本周已做"这类状态必须先种** | 对已完成的账号再跑一次，看是否重花资源 | 差点重刷 42 台剿灭（省下 ~4000 理智靠手工种状态） |
| **G7 真核对** | 验收看**真结算**（`ops/logs/*.out` 任务链 `Completed`），不看进程是否活着 | 抽查 3 台的 .out | 早期只看"进程起来了" |

## 4. 现状与补齐

- 已补：G2（日志落盘）、G3（启动回收 + `SweepOrphans`）、G4（并发位 + 清扫）、G5（加载失败大声报错）、G6（任务状态先种）。
- 待补：**G1 优雅停止的常规化**（收到 stop 要等在场任务收尾并停机；强杀只在最后手段）；
  **L1/L2 的固定脚本**（`fleet canary <id>` / `fleet batch 5`），让分级不靠人记。
- 旧 PS 栈（我们 5 台）作为**回滚位**保留：Go 侧出问题时，5 台不受影响；49 台可退回 PS 轮转器（已验证可用一次）。
